# Foto Geotag

Aplikasi Android untuk menambahkan stempel lokasi ke foto: peta satelit kecil, nama daerah,
alamat lengkap, koordinat Lat/Long, dan tanggal-jam. Semua teks bisa diedit sebelum disimpan.

## Cara pakai
1. Tekan **Kamera** untuk memotret, atau **Galeri** untuk memilih foto yang sudah ada.
2. Lokasi dan alamat terisi otomatis (dari data foto atau GPS ponsel). Ubah teks apa pun bila perlu.
   Kalau koordinat diubah, peta ikut diperbarui; tekan **Cari alamat** untuk mengisi alamat dari koordinat baru.
3. Ketuk kolom **Tanggal** atau **Jam** untuk mengubahnya. **Sekarang** mengembalikan ke waktu saat ini.
4. Tekan **Simpan** (masuk ke galeri, folder Pictures/FotoGeotag) atau **Bagikan**.

Butuh internet untuk peta satelit (Esri World Imagery) dan pencarian alamat.

## Membuat APK
Unggah proyek ini ke repository GitHub. GitHub Actions otomatis membuat APK dan
menerbitkannya di halaman **Releases** (bisa diunduh langsung tanpa login).
Atau buka di Android Studio → Build → Build APK(s).
